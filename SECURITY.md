# Security policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature instead of a public
issue. Include enough information to reproduce the problem without sharing
Duke Energy credentials, Home Assistant secrets, account numbers, addresses,
or unredacted bills.

This integration reads local Home Assistant Recorder statistics. It should not
request or store Duke Energy credentials or make direct Duke Energy network
requests. Treat any behavior that contradicts this statement as a security
issue.
